## A. 사실 확인 — 당신의 지적 중 원문과 다른 것

### A-1. "문의 관리와 견적 관리를 통합하라" 
- **유지/철회 여부:** 철회
- **이유:** 두 장의 화면과 상태값의 의도가 명확히 다르며, 각각의 사용 목적에 따른 구분이 필요합니다. 상태 8개를 혼합할 경우 사용자 혼란이 우려됨.

### A-2. "가입코드 용어가 '코드'·'가입 코드'로 섞여 있다"
- **유지/철회 여부:** 철회
- **이유:** 원문에서 해당 용어가 일관되게 '가입코드'로 사용되고 있었음을 확인했습니다.

### A-3. "'사장님께 재설정을 요청하세요'를 추가하라" 
- **유지/철회 여부:** 철회
- **이유:** 원문에 이미 명확하게 안내되어 있으며, 별도의 추가 설명이 필요하지 않다고 판단됩니다.

### A-4. "비밀번호 분실 방침이 빠져 있다"
- **유지/철회 여부:** 유지
- **이유:** 비밀번호 분실 시 대처 방안이 직원 장에서는 누락되어 있으며, 이 정보가 필요한 사용자가 쉽게 접근할 수 있도록 배치할 필요가 있습니다.

## B. 구조상 해로운 제안

### B-1. "계정 만들기 3단계를 표로 바꿔라"
- **유지/철회 여부:** 철회
- **이유:** 현재 문서의 포맷이 시각적 순서를 강조하며, 표 사용 시 시간 순서의 혼동이 발생할 수 있습니다.

### B-2. "각 장 첫머리에 요약을 넣어라"
- **유지/철회 여부:** 수정
- **7·8장 요약 문장:** 
  - **7장 요약 문장:** "요율을 갱신하고 단가의 변경 이력을 관리하는 방법입니다."
  - **8장 요약 문장:** "새로운 목적지를 추가하고 관련 속성을 설정하는 절차입니다."

## C. 1라운드에서 답하지 않은 질문 — 여기가 본론입니다

### C-1. 첫날 경로
- **필수 장/절 목록:** 1장 - 시작하기, 2장 - 하루 흐름 한눈에
- **배치 방법:** "시작하기" 장에 첫날 필수 장/절로 표기하며, "하루 흐름 한눈에"를 두 번째로 이어서 배치.
- **나머지 장 안내 방법:** 머리말 섹션에 "나머지 장은 필요시 참조하세요" 문구 추가.

### C-2. 눈이 미끄러지는 구간 — 구체적으로 3곳
1. **원문 인용:** "고객이 직접 뽑은 게 아니라 담당자가 조건을 넣어 견적을 만드는 도구입니다. 전화 상담 중에 바로 뽑아 보낼 때 씁니다." 
   - **문제:** 문장이 길고 복잡함.
   - **고쳐 쓴 문장:** "이 도구는 고객이 직접 견적을 뽑지 않은 경우, 담당자가 입력한 조건으로 견적을 만드는 방식입니다. 전화 상담 중 즉시 견적을 보낼 때 사용합니다."

2. **원문 인용:** "가입코드를 정합니다 설정 → 직원 계정 관리 → 직원 가입코드에 영문·숫자 6–40자로 넣고 저장합니다." 
   - **문제:** 구문 이해가 어려움.
   - **고쳐 쓴 문장:** "가입코드를 설정합니다: 설정으로 이동 → 직원 계정 관리 → 직원 가입코드를 입력하고 저장합니다(영문·숫자 6–40자)."

3. **원문 인용:** "담당자가 직접 보내려면 상세 → 🔗 견적서 링크 발급 — 링크가 만들어지고 클립보드에 복사됩니다."
   - **문제:** 설명이 부족함.
   - **고쳐 쓴 문장:** "담당자가 직접 견적서를 발급하려면, 상세 화면에서 🔗 '견적서 링크 발급'을 클릭하세요. 링크가 생성되어 클립보드에 복사됩니다."

### C-3. "고장인가, 원래 그런 건가"
- **문서에 답이 없는 것:** 
  1. 로그인 후 메일 수신 지연 시 대처 방법.
  2. 견적 산출 후 저장되지 않을 때의 해결 방법.
  3. 일정 관리에서 '이 코스 삭제'가 작동하지 않을 때의 조치 방법.

### C-4. 인쇄본
- **변화 필요 요소:** 
  - 목차를 인쇄본에서도 확인 가능하게 페이지 상단에 추가.
  - 인쇄된 페이지 번호를 각 페이지 하단에 추가.
  - 버튼 위치나 대체 텍스트를 인쇄물에 명시하여 사용자 혼란 줄이기.
